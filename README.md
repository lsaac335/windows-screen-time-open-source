# 屏幕时间 ScreenTime

一款本地运行的 Windows 屏幕时间统计工具，展示亮屏、前台时长、按空闲规则估算的活跃时长及应用排行。当前版本 0.4.0。

*界面示意图，数据为示例。*

## 功能介绍

![应用统计和桌面小组件的功能示意](docs/images/features.svg)

- 默认显示桌面浮动小组件；点击组件打开完整统计面板，点击“收起”直接返回组件。
- 按日期或近七天查看应用时长、柱状图和小时分布。
- 前台与活跃双指标，可切换对应的应用柱状图、排行和趋势。
- 可选空闲过滤：默认 5 分钟，可设 1/3/5/10/15/30 分钟，支持按应用例外。
- 独立线程监听前台事件，按事件发生时间划分归属，每秒校验，减少界面卡顿影响。
- 完整面板按需创建，收起后释放；历史按日期读取并限制缓存，图标只解码到 32px，应用列表每页最多 25 项。
- 可选系统媒体播放识别：开启时才加载媒体组件；仅当前台应用与播放来源明确匹配时补计空闲，标注“媒体推测”。
- 可选 XInput 手柄识别，过滤摇杆死区；未连接时低频探测，默认关闭。
- 深色模式、托盘运行、可选开机自启和 CSV 导出。
- 数据保存在本机，不读取窗口标题、网址或按键内容。

活跃时长是估计值，不能证明本人持续在场。媒体识别仅支持接入系统媒体控制的软件，浏览器只能匹配到应用，无法确认具体标签页；来源不明时不补计。背景播放、下载不增加前台时间。阅读等场景仍可单独延长阈值。应用归属以获得焦点的前台窗口为准；本程序自身排除在应用统计之外。

升级会保留旧统计，并在改写旧格式日文件前保存原始副本。旧版没有保留空闲时的应用归属，因此旧日期的前台时长显示“≥”已知下限。新版数据格式需要 0.3 或更高版本读取。

## 下载使用

访问 [Windows 版本下载页](https://github.com/lsaac335/windows-screen-time-open-source/releases)，下载 Windows x64 压缩包，解压后运行 `ScreenTime.exe`。需要 Windows Desktop Runtime 8 或兼容版本。

## 构建

需要 Windows 10 1809 或更新版本、x64 与 .NET SDK 6。项目使用 WPF 和微软 Windows SDK 的 WinRT 接口，首次构建需从 nuget.org 下载构建依赖；成品运行不联网，需 Windows Desktop Runtime 8 或兼容版本。在项目目录运行：

```powershell
.\build.ps1
```

编译结果位于 `首版` 文件夹，启动 `ScreenTime.exe`。更多操作说明见 [使用说明](使用说明.md)。

本项目目前为试用版本，使用数据保存在程序目录的 `data` 文件夹中。
