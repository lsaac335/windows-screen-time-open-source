# ScreenTime 0.5.0 本地验证

日期：2026-10-31（Asia/Hong_Kong）。范围：D:\屏幕使用时间。以下为0.5.0功能阶段的发布前验收记录；这些功能随0.5.1统一发布。

## 统计规则

- 保留前台、活跃、亮屏原有口径，仍自动排除本程序自身。
- 新增独立“可见时长”：只在采样已确认解锁、亮屏、本地活动会话且未暂停时累计，不扣键鼠空闲；它是窗口展示估算，不是注意力。
- 使用当前桌面、可见、非最小化、非 cloaked 顶层窗口，按屏幕范围与 Z 顺序估算矩形遮挡；有效面积至少 4096 物理像素且不少于该窗口屏内面积的 10%。全遮挡或屏外窗口不计；不激活、穿透输入的工具覆盖层不归属应用。
- 不同应用允许并行；同应用的所有合格窗口仅累计一次。应用可见总和可以超过亮屏，不加入设备总量。没有旧日期的可见状态，不回填历史。
- 普通窗口作为矩形遮挡；不能确定透明层完全不透明时，不用其整个矩形覆盖后方。异形、透明、部分特殊全屏窗口仍可能误差。物理显示器单独断电、不同虚拟桌面实机切换的组合没有全面测试。
- 活跃仍主要按前台与空闲判断，未新增全局键鼠内容采集或滚轮接收窗口归属；并排阅读由独立可见指标补充。既有媒体补计仅匹配前台应用，默认关闭；没有新增跨窗口媒体实际观看时长。

## 占用设计

复用独立采集 STA 和现有 1 秒时钟，不增加线程。窗口创建、显隐、位置、层级和最小化事件只置脏；最短 1 秒合并后校验，静止时每 3 秒补查。窗口枚举上限 4096、遮挡碎片上限 1024，超出或 API 无法确认时跳过该次可见归属，原前台采集继续。

不保存截图、窗口标题或每秒窗口列表。只在 data/visibility 按日保存应用小时累计、采集覆盖时长、首末时间和去重游标；缓存最多 8 天，随面板关闭可缩至 1 天。明细保留 90 天，汇总 365 天；删除日期/全部记录连同写入临时文件处理。主日文件仍为 schema 2，不改写既有统计定义。CSV RuleVersion 5 新增 app_visible、visible_parallel_sum、visibility_coverage。

设置可单独关闭可见采集，立即卸载相关 WinEvent 监听与虚拟桌面 COM 对象，历史保留。进程路径查询先用 1024 字符缓冲区，仅不足时扩容，避免每次固定分配 32768 字符。

## 后台和任务栏

- 小组件 ShowInTaskbar=false；保留托盘，完整面板仍有正常任务栏入口。
- 设置、托盘、组件菜单新增“隐藏窗口，后台记录”，关闭两个视图、解绑界面事件、修剪视图缓存，独立采集继续，不改下次启动组件偏好。
- 再次打开 EXE/桌面快捷方式会唤回同一进程的完整面板。收起可重新创建组件；托盘可显示组件或退出。
- 真实后台采样从 ticks 130 到 251，持续 121 个采样周期，DashboardWindows=0、WidgetVisible=null、Status=正在记录；未停表。
- 可见统计开关实测关闭后 visibility=off、visibilitySamples=0；再次开启已保存，最终恢复为开启。

- 合计 331 项。公开源码工作副本 tests/CoreTests 可重跑逻辑检查与缓存检查。
- 现有 8 天原记录副本的亮屏、活跃、锁屏总量升级完全一致；本地更新后 8 天亮屏、活跃、前台、锁屏总量均保持或正常增长，偏好和桌面快捷方式保留。
- 真实界面查看了深色概览、可见柱状图与排行、设置入口、后台隐藏与再次打开。小组件未在可枚举任务栏窗口清单中出现，运行状态 WidgetVisible=true、WidgetShowInTaskbar=false。
- 本次测试初期的工具透明覆盖层和窗口测试进程曾被原实现计入新可见表；已加通用覆盖层过滤并重新通过真实窗口检查。备份后仅移除两项本轮新增的可见测试条目，未修改原始前台/活跃/亮屏日记录。

## 资源短测与限制

同一新版、相同桌面、独立采集模式，无面板/组件/托盘/数据持久化；两进程同时采样，预热 10 秒后各 60 秒、13 点。只用于估算新增采集模块的边际开销，不能代表完整应用，也不是严格隔离的性能基准。

| 模式 | 工作集中位数 MiB | 私有内存中位数 MiB | 60 秒累计 CPU 秒 |
|---|---:|---:|---:|
| 可见统计关闭 | 91.97 | 50.10 | 0.125 |
| 可见统计开启 | 99.69 | 52.32 | 0.094 |

新增约 7.71 MiB 工作集、2.23 MiB 私有内存。CPU 差值处于短测噪声范围，不能称开启更省 CPU。两组均未加载媒体投影程序集。

完整应用打开过面板再隐藏全部窗口后，2 分钟、25 点：工作集平均约 207.71 MiB，私有内存平均约 125.15 MiB；120 秒累计 CPU 0.09375 秒。关闭视图不会保证框架已触及的全部内存立即退还。旧版已热运行组件的 65 秒样本约 190.80/136.43 MiB，运行经历不一致，不用于宣传新版工作集下降。

最终版本重启后仅运行默认组件，预热约 20 秒后 2 分钟、25 点：工作集中位数 174.35 MiB，私有内存中位数 96.29 MiB；120 秒累计 CPU 7.40625 秒。该次组件保持激活可见，旧样本的组件被遮挡，CPU 与旧版不可直接比较。默认可见采集正常，未加载媒体识别；不是全天或一般硬件资源承诺。

未验证 24 小时内存趋势、全部锁屏/物理关屏/睡眠/远程会话组合、实体手柄或 Mac 行为，未使用眼动或屏幕识别。窗口可见采样存在约 1–3 秒校正延迟。
